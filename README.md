# Jindharma

Interactive study material on Jain Dharma, from Digambar sources, in English and Hindi.

## Pages
- [Karma Siddhant](karma-siddhant/) — the eight karmas, flow charts, and the 14 Gunasthanas

## Adding a new page
1. Create a folder, e.g. `tattvarth-sutra/`, with an `index.html` inside.
2. Add one entry to the `TOPICS` list in the root `index.html`.

Each page is a single self-contained HTML file (no build step).
